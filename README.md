# Taller de Tecnologías 1 — Obligatorio 1 (Bash)

Obligatorio de **Taller de Tecnologías 1** (Universidad ORT, entrega 15/05/2023). Script de **Bash** con un menú interactivo:

- ingreso de usuario y contraseña, y cambio de contraseña;
- elección de una letra;
- búsqueda en un diccionario de las palabras que terminan con esa letra, y conteo;
- guardado del resultado en un archivo, con fecha y hora del informe;
- registro de la fecha del último ingreso de cada usuario.

## Uso

```bash
bash obligatorio.sh
```
